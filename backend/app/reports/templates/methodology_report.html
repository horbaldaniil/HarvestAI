LOOCV (leave-one-oblast-out) — найчесніша метрика просторової генералізації для GIS-моделей (Roberts et al. 2017). Test R² нижче від LOOCV — нормально для невеликих датасетів.

2. Cross-crop лідерборд

Топ-{{ leaderboard_top_n }} пар (культура × модель) за test R². Stacked Ensemble (Wolpert 1992) — позначений фіолетовим — як правило, перевершує одиничні base learners.

3. Карта помилок по областях

Mean absolute residual на 2023 test-split, агреговано по областях. Жовтий = низький error, темно-червоний = високий. Області, де модель систематично помиляється, — кандидати на додаткові фічі або зональні sub-models у магістерській роботі.

4. Глобальна важливість фіч (SHAP)

Mean | SHAP value | per feature (Lundberg & Lee 2017). Які входи реально драйвлять прогноз. Якщо в топі стоять погодні/NDVI фічі — модель відображає агрономічну логіку; якщо тільки centroid_lat — сигнал слабкий, потрібно більше даних або кращих фіч.

5. Криві навчання

Test R² як функція обсягу тренувальних даних. Якщо крива плато на 100 % — модель bias-limited (потрібні інші фічі); якщо ще піднімається — data-limited, додавання даних допоможе.

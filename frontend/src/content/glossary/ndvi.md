**NDVI (Normalized Difference Vegetation Index)** — найпоширеніший індекс для
оцінки стану рослинного покриву. Базується на тому, що здорове листя
**сильно поглинає червоне світло** (Red, ~660 нм) і **сильно відбиває
ближнє інфрачервоне** (NIR, ~840 нм).

### Формула

```
NDVI = (NIR − Red) / (NIR + Red)
```

### Інтерпретація

| Значення | Що означає |
|----------|------------|
| `< 0` | Вода, сніг, тіні |
| `0 – 0.2` | Голий ґрунт, асфальт, скелі |
| `0.2 – 0.4` | Розріджена рослинність, рання вегетація |
| `0.4 – 0.6` | Сільгоспкультури у фазі активного росту |
| `0.6 – 0.8` | Здоровий зелений покрив (пік сезону) |
| `> 0.8` | Дуже густа рослинність (рідко для польових культур) |

### Як HarvestAI використовує NDVI

- **Heatmap** — піксельна карта поля для пошуку проблемних зон
- **Time series** — графік розвитку посівів від посіву до врожаю
- **Ознака для XGBoost** — `ndvi_peak`, `ndvi_mean_*`, `ndvi_integral` як фічі прогнозу врожайності
- **Z-score аномалії** — порівняння поточного значення з історичною нормою для ISO-тижня

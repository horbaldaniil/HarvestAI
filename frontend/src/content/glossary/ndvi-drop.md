title: Аномалія NDVI drop
short: Різке падіння NDVI відносно норми

---

**NDVI drop** — тип аномалії, яку HarvestAI створює коли поточне значення
NDVI для поля **значно нижче** історичної норми для цього тижня сезону.

### Як вираховується

1. Для кожної культури зберігаються **сезонні норми** — середнє та
   стандартне відхилення NDVI по тижнях вегетації (з історії 2017-2023)
2. Для поточного спостереження беремо `z = (value − mean_week) / std_week`
3. Пороги:
   - `z ≤ −2.5` → **critical** alert
   - `−2.5 < z ≤ −1.5` → **warning** alert
   - `z > −1.5` → норма

### Що це значить агрономічно

NDVI може впасти з кількох причин:
- **Шкідники, хвороби** — раптове пожовтіння
- **Полягання** (lodging) — після зливи або вітру
- **Передчасний скос/обробка** — антропогенна (не справжня аномалія)
- **Помилка зйомки** — рідкісно, але можливо (тонка хмара, тінь від хмари)

### Що робити коли бачите такий alert

1. Подивіться **NDWI поряд** — якщо він теж впав, ймовірно водний стрес
2. Подивіться **погоду 14 днів назад** — гроза? буря?
3. Відкрийте **heatmap** на дату аномалії — локальна проблема чи на всьому полі
4. Запитайте чат-бота — він зведе ці дані разом

### Технічна нота

Норми обчислюються один раз і зберігаються у
`backend/data/processed/seasonal_norms.json`. Якщо для конкретного
тижня немає історичних даних — детектор пропускає таке спостереження.

**SAVI (Soil-Adjusted Vegetation Index)** — модифікація NDVI, яка
зменшує вплив відкритого ґрунту на сигнал. Найкорисніший у фазах, коли
**рослини ще не закрили землю** (рання вегетація, після проріджування,
або кілька рядів кукурудзи).

### Формула

```
SAVI = ((NIR − Red) / (NIR + Red + L)) × (1 + L)
```

Де `L` — корекційний фактор:
- `L = 1.0` — для дуже розрідженого покриву (рідкісне використання)
- `L = 0.5` — стандарт для більшості польових культур (це використовує HarvestAI)
- `L = 0.25` — для густого покриву (наближається до NDVI)

### Коли SAVI кращий за NDVI

| Фаза розвитку | NDVI | SAVI |
|---------------|------|------|
| Прорість (3-5 листків) | Завищений | Точний |
| Кущіння | Подібно | Подібно |
| Пік біомаси | Точний (краще EVI) | Подібний |
| Дозрівання | Хороший | Подібний |

### У HarvestAI

SAVI рендериться як heatmap для ранніх фаз сезону, коли NDVI ще не
відображає реальну картину через велику частку ґрунту в пікселях.

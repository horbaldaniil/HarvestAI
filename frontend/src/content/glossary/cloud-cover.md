**Хмарність (cloud cover)** — відсоток пікселів знімка, які закриті
хмарами або їхньою тінню. Один з найбільших технічних викликів
супутникового моніторингу.

### Як HarvestAI з нею бореться

1. **Фільтрація на запиті** — Statistical API запитується з
   `mosaicking: "ORBIT"` та `maxCloudCoverage: 30%`. Це означає що
   Sentinel Hub скомпонує знімок з кількох пролетів, шукаючи менш
   хмарну версію кожного пікселя.
2. **Зберігання NULL** — якщо для якогось ISO-тижня не вдалося отримати
   чисті дані, в БД зберігаємо рядок з `ndvi_mean = NULL` та
   `cloud_cover` (для звіту). Це не «помилка», а «cloud gap».
3. **Інтерпольовані графіки** — на UI лінія NDVI має розриви на місцях
   NULL, замість того щоб домальовувати через них криву.

### Що бачить користувач

| Cloud cover на дату | Поведінка UI |
|---------------------|--------------|
| `0 – 20%` | Точка на графіку, heatmap доступний |
| `20 – 50%` | Точка може бути присутня, але з підвищеним шумом |
| `> 50%` | Розрив — точка пропускається або з NULL |
| `100%` | Гарантовано NULL |

### Поради

- **Зимовий сезон** — дані рідкісні через хмарність + короткий день.
  Це нормально.
- **Літо** — найкраще покриття, особливо червень-серпень
- Якщо потрібен heatmap на конкретну дату — спершу подивіться на
  графік: якщо точка чорна / є — heatmap буде; якщо розрив — на цю
  дату немає знімка.
